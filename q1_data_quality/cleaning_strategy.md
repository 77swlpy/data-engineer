# Q1.3 清洗策略

统一处理：订单号、商品编码和客户 ID 按文本保存，统一数量、单价和日期类型。商品描述先统一大小写和空格，再用同一编码下已核实的商品明细建立标准名称。例如 20713 的 JUMBO BAG OWLS 可作为商品名称，`Found` 和 wrongly coded 23343 应保留为业务备注。缺描述时，仅在编码能唯一对应已核实商品名、且该行确属商品明细时补填。已发现的 4,382 条缺描述记录全部零价、数量有正有负，应保留原样待核查。字段完全相同的行，只有确认是重复导入才去重。

A．销售报表
保留符合销售口径的缺 ID 商品明细。按下单金额、取消冲减和折扣分别汇总，运费及坏账单列。保留数量为正负 80,995 的两条极值明细，分别计入对应业务，避免截断后破坏金额抵消。

B．RFM 客户分群
仅用可归属到稳定客户 ID 的有效购买。按不同发票数计算频次，取消记录不增加购买次数。若消费金额采用净额，只将可核实的取消冲减计入对应客户，未匹配项单列。

C．商品推荐
用商品编码构建购物篮，同一发票内同一商品只计一次，排除取消、费用和调整行。匿名发票可用于商品共现，个人历史推荐需有客户 ID。
