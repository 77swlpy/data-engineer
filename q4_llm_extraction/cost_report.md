# 成本与运行报告

## 一句话结论
共 297 次真实 API 调用，消耗 483,120 tokens（输入 350,638、输出 132,482）。接口只返回 token 数、不返回金额，所以"花了多少美元"要用你的单价换算，token 部分是实测值。

## 1. 每个阶段用了多少 token（实测）
| 阶段 | 调用 | 输入 | 输出 |
|---|---|---|---|
| 连通性测试 | 1 | 67 | 35 |
| 完整 Prompt 逐条跑 132 条 | 132 | 152,967 | 43,775 |
| 同样 132 条重跑（补失败日志） | 132 | 157,239 | 44,837 |
| 22 条失败重试 | 22 | 24,604 | 16,835 |
| 批量 10 测试 | 2 | 5,864 | 12,793 |
| 紧凑方案 20 条测试 | 1 | 1,113 | 1,664 |
| 紧凑方案 132 条验证 | 7 | 8,784 | 12,543 |
| 合计 | 297 | 350,638 | 132,482 |

## 2. 最终方案的单条成本
132 条共 21,327 tokens，平均每条 161.6 tokens（输入 66.5 + 输出 95.0）。
换算：1,000 条约 161,600 tokens；14,445 条约 233 万 tokens。

## 3. 换算成钱
公式：金额 = 输入 tokens / 1,000,000 × 输入单价 + 输出 tokens / 1,000,000 × 输出单价。

举例（假设输入 0.27、输出 1.10 USD/百万 tokens）：
- 单条：0.000122 USD
- 132 条验证：0.0162 USD
- 全部 297 次调试调用：0.2404 USD
- 全量 14,445 条：1.77 USD

若你的单价是输入 0.14、输出 0.28，则全量为 0.52 USD。把公式里的单价换成你的实际价格，就是正式账单金额。

## 4. 全量需要多少时间和钱
- 时间：723 次请求，单批实测约 5 秒，并发 10，约 6 分钟。
- 钱：2.33M tokens。要控制在 3 USD 内，平均单价不能超过约 1.29 USD/百万 tokens。

## 5. 没有发生的费用
- 全量 14,445 条没有运行，因此没有这部分费用。
- 2 条证据失败的记录没有重试、也没有算进成功结果。
