# Pipeline 设计说明（V2.1）

数据范围为 review_score≤3 且正文非空，共 14,445 条。原始 99,224 行逐行生成 source_row_id（文件指纹加行号），review_id 只作业务字段，避免重复 ID 造成结果覆盖。分流只覆盖 38 条（0.26%）纯情绪短文本，其余 14,407 条交给 LLM；精确文本缓存可复用 622 条（4.31%）。

模型固定 deepseek-flash，葡萄牙语原文直接抽取，不先机器翻译，英文证据翻译与抽取在同一次调用完成。Prompt 写死七类定义和边界，强制证据为原文逐字子串、每类最多一条、同一事实不得重复归类；V2.1 针对 other 误报和 seller_communication 漏报各加了一条明确规则。

批量 20 条一请求、关闭思考、max_tokens 取 3000。每批校验 sid 完整性、类别与数值范围、证据是否能在原文定位，失败记录单独隔离并有限重试。132 条开发验证得到 Micro F1 0.9649、整条完全一致 93.13%、证据 154/154 可回溯；另抽 30 条独立样本并已生成模型预测，但人工标签尚未完成，因此不宣称泛化准确率。成本方面单条约 210 tokens；按推导单价全量约需 32.1 元，而账户余额只有 5.76 元，因此没有启动全量，也没有把 131 条验证结果冒充全量结果。
