# 准确率评估报告（V2.1，按修正后的口径）

## 1. 先说结论
- **96.49% 不是“准确率”**，是模型与“单一参考标注”的 micro 一致率；参考标注由研究执行者生成，且参与过 Prompt 设计，属于**样本内一致性**。
- 更能反映真实短板的综合指标是 **Macro F1 = 90.47%**；两者差 6 个百分点，差额主要来自小类别。
- 严格整条完全一致率 **93.13%**（122/131）。

## 2. 类别支持数与分类别表现（131 条，159 个金标）
| 类别 | 支持数 | P | R | F1 |
|---|---|---|---|---|
| quality_defect | 36 | 1.000 | 0.944 | 0.971 |
| delivery_late | 32 | 1.000 | 1.000 | 1.000 |
| missing_item | 29 | 0.935 | 1.000 | 0.967 |
| wrong_product | 26 | 0.962 | 0.962 | 0.962 |

| packaging | 9 | 1.000 | 1.000 | 1.000 |
| **other** | **3** | 1.000 | 0.333 | **0.400** |

前四类占金标的 77%，micro 被它们主导；other 只有 3 条，F1 0.40 对 micro 几乎无影响，却正是边界能力的真实体现。

## 3. Micro / Macro / 完全一致
| 指标 | 数值 | 说明 |
|---|---|---|
| Micro P / R / F1 | 0.9805 / 0.9497 / **0.9649** | 按（评论，类别）对计，受高频类主导 |

| 整条完全一致 | 122/131 = **93.13%** | 传统意义的整条匹配率 |

## 4. 指标口径的已知缺陷
1. **11 条金标为空的评论几乎不参与计分**（8.4% 样本）：多标签 micro 只算 TP/FP/FN，模型判空它们时完全不计；只有多抽时才以 FP 出现。“该空能否空”没有被单独度量。
2. **V1 对比有两个分母**：V1 官方 130 条有效为 0.9579，共同 131 条重算为 0.9585；V2.1 的 0.9649 对应 131 条。差距小，但报告应统一注明。
3. **未评其他字段**：severity、actionable、sentiment、confidence 均无金标，四项指标为“暂无法计算”。
4. **标签歧义未裁决**：3 个 FP 与 8 个 FN 中包含边界争议（如“描述不清只收到一盒”判 wrong_product 还是 missing_item），当前一律按模型错误计。

## 5. 幻觉与证据
- 证据错误率：**0/154 = 0.00%**（全部引文可在原文逐字定位）。
- 语义幻觉率：**暂无法计算**。需要人工对 154 个预测问题做“引用不存在 / 引用真实但解释错误 / 原文支持”三分类；引文真实不等于语义正确。

## 6. 标签来源与独立性声明
- 132 条参考标签由研究执行者逐条阅读生成，**不是独立人工标注**，无第二标注者、无 Kappa。
- 132 条参与过 V1/V2/V2.1 的 Prompt 设计，只能作开发回归，不能宣称泛化准确率。
- 30 条独立样本已生成模型预测，人工标签为空（pending_human_annotation），因此不报独立结果。

## 7. 建议的对外表述
> 在 131 条开发集上，模型与单一参考标注的 micro 一致率 96.49%、macro F1 90.47%、整条完全一致 93.13%，证据可回溯率 100%。该结果为样本内一致性，参考标注非独立人工，不能作为泛化准确率。
